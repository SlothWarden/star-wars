# **Requires Fabric API
# This is a Star Wars mod!

I love Star Wars, so I decided to create a fun but completely overpowered Star Wars mod! It was created with Fabric and some aspects of it were created with the Fabric modding tutorial
This mod adds:
Lightsabers,
A Suspicious Substance,
A Dioxis Injection,
A Clone Nutrition Cube
Shock Batons(Use the key you would to guard with a shield to create lightning bolts!)
